## 공통 사항 (4종 모두 해당)

- **프레임워크**: `IGameContent` 상속 씬 1개. `framework.h`(`_ECONTENT`)·`MainContent`(AddContent)·`.vcxproj`/`.filters` 등록. 전각 1칸=콘솔 2칸(`x*2`), 색 상수(0~15).
- **인코딩**: 전각/한글 포함 `.cpp` 는 **CP949 저장**(UTF-8 작성 → PowerShell 재인코딩), 헤더는 ASCII. [CLAUDE.md](../CLAUDE.md) 규칙.
- **글리프 검증 세트**(기존 확인됨): `■ ● ◆ ★ ▲ ▶ ▼ ◀ ♥ ♣ □ ▒(U+2592) ≡(U+2261) ◎(U+25CE) ▨(U+25A8) ♠`. 그 외는 **구현 전 왕복 검증**.
- **공용 자산 재사용**: 오브젝트 풀 [`Pool.h`](../Main/Content/Pool.h), Maze의 BFS/A* 경로탐색, Battle City의 타일맵/충돌 패턴.
- **뒤로가기 규칙**: 인게임 ESC→타이틀, 타이틀 ESC→종료([handover.md](../handover.md) §8).

## 1. Pac-Man — 8단계: 성격별 AI + 유한상태기계 ⭐ (최우선 추천)

> ✅ **정식 GDD로 승격됨** → [`PacManContent_GDD.md`](PacManContent_GDD.md) (프레임워크 규격 반영, 글리프 검증 완료). 아래는 요약.

**한 줄**: 고정 미로에서 펠릿을 먹으며 4마리 고스트를 피한다. 파워펠릿을 먹으면 잠시 반격.

### 처음 배우는 핵심 기술
- **고스트 성격별 타게팅 AI** — Blinky(직접추적)/Pinky(앞질러)/Inky(협공)/Clyde(변덕)마다 **다른 목표 좌표 계산**. "AI = 목표 선정 + 경로 선택".
- **유한상태기계(FSM)** — 고스트 상태 `CHASE ↔ SCATTER ↔ FRIGHTENED ↔ EATEN` 시간/이벤트 전이.
- **고정 맵 경로탐색** — 교차로마다 목표 방향으로 다음 한 칸 결정(**Maze의 BFS 재사용** 가능). 역방향 금지 규칙.

### 화면 / 글리프(안)
- 플레이어(팩맨): `●`(YELLOW) 또는 방향별 `▶◀▲▼`. 고스트: `▲`/전각 색 구분(RED/PINK≈PURPLE/SKYBLUE/DARKYELLOW), FRIGHTENED 시 `▒`(DARKBLUE) 깜빡.
- 벽: `■`(BLUE), 펠릿: `·`(단각, WHITE), 파워펠릿: `●`(WHITE) 깜빡, 워프 터널.
- 필드: 타일 그리드(예 28×31 축소 또는 커스텀). `MazeContent`/Battle City 타일 렌더 패턴 차용.

### 시스템 요약
- 이동: 타일 그리드 + 이동 틱(팩맨·고스트 각 틱). 교차로에서만 방향 결정.
- 상태: SCATTER↔CHASE 주기, 파워펠릿→FRIGHTENED(고스트 도망·먹기 가능→EATEN→둥지 복귀).
- 점수: 펠릿 10 / 파워펠릿 50 / 고스트 연쇄 200·400·800·1600 / 과일 보너스. 전 펠릿 소진 → 클리어.

### 러프 Phase
1. 맵·펠릿·팩맨 이동/먹기. 2. 고스트 1마리(Blinky) CHASE + 충돌/생명. 3. 4마리 성격 + SCATTER/CHASE/FRIGHTENED FSM. 4. 파워펠릿 연쇄·과일·스테이지·하이스코어.

### 주의
- **미검증 글리프**(고스트 몸·과일 등) 왕복 검증. 팩맨 "입 벌림" 애니는 방향 글리프 토글로 대체.
- 교차로 판정·역방향 금지가 AI의 핵심 — 여기에 학습 가치 집중.

## 2. Breakout / Arkanoid — 9단계: 2D 벡터 반사 물리

**한 줄**: 패들로 공을 튕겨 위쪽 벽돌을 모두 깬다.

### 처음 배우는 핵심 기술
- **연속 2D 벡터 물리 + 반사** — 공 `(x,y)` float + 속도 `(vx,vy)`. 벽/패들/벽돌 충돌 시 **법선 기준 반사**(vx/vy 부호 반전, 패들 접촉 위치로 각도 변화). Dino의 1D 중력에서 **2D 벡터**로 확장.
- **연속 충돌 감지(스윕)** — 빠른 공의 터널링 방지(다음 위치까지 경로 검사).
- **아이템/멀티볼** 등 상태 변형.

### 화면 / 글리프(안)
- 공: `●`(WHITE), 패들: `■■■`(SKYBLUE) 또는 가로 막대. 벽돌: `■`/`▒` 색상 층(내구도별 색), 강철 벽돌 `■`(GRAY, 불파괴).
- 필드: 상단 벽돌 그리드 + 좌우/상단 벽 + 하단 낙사선. 논리 좌표 → `x*2`.

### 시스템 요약
- 공 이동: 매 프레임 float 이동 + 반사. 패들: A/D 또는 ←→ 이동(연속).
- 벽돌: 그리드 배열, 피격 내구도-1, 0이면 제거·점수. 전멸 → 클리어.
- 파워업(드랍): 멀티볼/확장패들/느리게/관통/캐치. **오브젝트 풀**(공·파워업·파편)로 관리.
- 생명: 공을 놓치면 -1.

### 러프 Phase
1. 패들·공·벽 반사·벽돌 그리드 파괴. 2. 벽돌 내구도/점수/클리어/생명. 3. 파워업(풀)·멀티볼. 4. 스테이지 레이아웃·하이스코어.

### 주의
- **각도 반사의 손맛**이 핵심 — 패들 접촉 위치(중앙/가장자리)로 반사각 조절. 콘솔 저해상도라 공 속도/틱 튜닝 중요(터널링).

## 3. 타일 플랫포머 — 10단계: 타일맵 충돌 해결 + 카메라

**한 줄**: 중력 받는 캐릭터로 타일 지형을 뛰어다니며 목표(깃발/코인)에 도달.

### 처음 배우는 핵심 기술
- **타일맵 vs AABB 충돌 해결(축 분리)** — x축 이동→겹친 타일로 밀어내기, y축 이동→바닥/천장 처리. **"충돌 감지"에서 "충돌 해결(resolution)"로**. Battle City의 타일 격자 재사용하되 **연속 이동 + 밀어내기**가 새 기술.
- **중력/점프 상태** — 접지(onGround) 판정, 가변 점프, 코요테 타임(선택).
- **카메라 스크롤** — 플레이어 추적 뷰포트(맵 > 화면). Dino는 자동 스크롤이었지만 여기선 **양방향 카메라**.

### 화면 / 글리프(안)
- 플레이어: `▲`/`◆`(YELLOW). 지형: `■`(땅, DARKYELLOW/GRAY), 코인 `★`(YELLOW), 가시 `▲`(RED), 목표 깃발 `♣`/`★`.
- 맵: 타일 배열(화면보다 큼) + 카메라 오프셋으로 가시 영역만 렌더.

### 시스템 요약
- 이동: 좌우(연속) + 점프(중력). 매 프레임 x/y 분리 이동 후 타일 밀어내기.
- 수집/위험: 코인 점수, 가시/낙사 → 생명-1·리스폰(체크포인트).
- 카메라: `camX = clamp(playerX - viewW/2, 0, mapW-viewW)`. 렌더는 `타일x - camX`.

### 러프 Phase
1. 타일맵 + 중력/점프 + 축분리 충돌. 2. 카메라 스크롤 + 코인/목표. 3. 위험/생명/체크포인트. 4. 적/이동발판·레벨 로딩(→ Sokoban의 파일 로딩과 연계).

### 주의
- **축 분리 순서**(x먼저 vs y먼저)와 모서리 끼임이 난제 — 작은 맵으로 먼저 검증. 콘솔 세로 해상도(25행)가 작아 **세로 스크롤/맵 스케일** 설계 주의.

## 4. Sokoban — 11단계: 데이터 주도 레벨 로딩 + 실행취소

**한 줄**: 상자를 밀어 모든 목표 지점에 올려놓는 퍼즐. 밀기만 가능(당기기 불가).

### 처음 배우는 핵심 기술
- **파일 기반 레벨 로딩(데이터 주도 설계)** — 레벨을 코드가 아니라 **텍스트 파일**(`#`벽, `$`상자, `.`목표, `@`플레이어)로 정의·파싱. 콘텐츠와 코드 분리. **파일 I/O 입문**([CURRICULUM.md](CURRICULUM.md) §12 저장/불러오기와 직접 연계).
- **실행취소(Undo) 스택** — 이동/밀기를 **커맨드로 기록**하고 되돌리기. 자료구조(스택) + 상태 스냅샷/역연산.
- **밀기 규칙 + 승리 판정** — 상자 앞 칸이 비어야 밀림, 모든 목표 덮이면 클리어.

### 화면 / 글리프(안)
- 플레이어 `▲`(YELLOW), 상자 `■`(DARKYELLOW), 목표 `◆`/`★`(RED), 목표 위 상자 `■`(GREEN, 완료), 벽 `■`(GRAY), 바닥 공백.
- 맵: 파일에서 로딩한 2D 배열. 작은 격자, `x*2` 렌더.

### 시스템 요약
- 이동: 방향키 1칸. 앞이 상자면 그 너머가 비었을 때 함께 밀기.
- Undo: 매 이동 전 상태(플레이어·상자 위치)를 스택에 push, `U`로 pop 복원. Redo(선택).
- 진행: 레벨 클리어 → 다음 레벨 파일 로딩. 이동수/최소수 채점(선택). `R`로 리셋.

### 러프 Phase
1. 파일 파싱·렌더·이동·밀기·클리어 판정. 2. Undo/Reset·이동수. 3. 레벨 진행(여러 파일)·최소수 채점. 4. 레벨 에디터/저장(심화).

### 주의
- **레벨 파일 포맷**을 먼저 확정(표준 Sokoban 기호 권장: `# $ . * @ +`). 파일 경로/인코딩(레벨 파일은 ASCII 권장). Undo 스냅샷은 상자 수가 적어 **전체 복사**로 충분.
